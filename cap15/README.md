# Laboratório – Validação de Formulários com HTML, CSS e JavaScript

## Descrição

Este projeto foi desenvolvido como atividade prática da disciplina de Desenvolvimento Web. O objetivo é criar um formulário de inscrição para novos alunos utilizando HTML, CSS e JavaScript, aplicando validações tanto pelo HTML quanto pelo JavaScript para garantir que os dados informados sejam válidos.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## Funcionalidades

* Formulário de cadastro completo;
* Validação de todos os campos obrigatórios;
* Validação em tempo real;
* Máscara para telefone;
* Indicador de força da senha;
* Confirmação de senha;
* Contador de caracteres da mensagem;
* Pré-visualização da imagem enviada;
* Validação da idade mínima de 16 anos;
* Armazenamento temporário dos dados utilizando `localStorage`.

1. Faça o download ou clone o repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Preencha o formulário e teste as validações implementadas.
