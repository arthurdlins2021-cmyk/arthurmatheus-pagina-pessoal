O Caminho da Iluminação

Olhando para esta página, você pode se perguntar o que ela faz. Afinal, é apenas um documento bem estruturado, mas sem graça.

O CSS Zen Garden convida você a relaxar e meditar sobre o código. Veja o que é possível transformar apenas modificando a folha de estilo de um documento HTML.

O que é isto?

Há claramente a necessidade de um design web moderno. O CSS Zen Garden foi criado para demonstrar o poder de separação entre conteúdo e design visual.

Como participar

Qualquer designer gráfico ou desenvolvedor web pode enviar um layout estruturado em CSS para fazer parte da galeria oficial.

Benefícios

Por que usar CSS? Acessibilidade, leveza nos arquivos, facilidade de manutenção e total liberdade criativa de posicionamento.

Requisitos

O desafio consiste em modificar unicamente o código CSS. Você não pode mexer em uma única tag do HTML original fornecido.
